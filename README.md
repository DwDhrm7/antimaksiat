# ANTIMAKSIAT®
### LATE NIGHT CULTURE. BE I AM.

**ANTIMAKSIAT.CO** is a high-end streetwear collective and e-commerce platform born from the strobe lights and basslines of the underground clubbing scene. We bridge the gap between floor-culture and premium editorial design for the generation that owns the night.

---

## ⚡ The Experience

This platform is designed with a **Brutalist / Grunge / Y2K** aesthetic, featuring:

*   **Sinematic Hero Intro**: A forced 5-second lock on a slow-zoom warehouse rave video, transitioning into a faded texture.
*   **Secure Item Flow**: A unique, simulated order system ("SECURE ITEM") that bypasses traditional payment gateways for a more exclusive, industrial checkout experience.
*   **Dynamic Archive**: A curated product catalog with filters and high-fidelity hover-to-flip product cards.
*   **The Archives**: A motion-blurred gallery capturing candid fragments of the underground culture.
*   **Responsive Typography**: Editorial-style layouts that adapt and react to the user's scroll depth.

## 🛠 Tech Stack

*   **Framework**: [Next.js](https://nextjs.org/) (App Router)
*   **Styling**: Vanilla CSS (Global Design System)
*   **Logic**: React (State Management & Intersection Observers)
*   **Media**: High-definition video background & generative thematic imagery.

## 🚀 Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
